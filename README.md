Disc Buddy
==================

An application to help parse TheDiscDb to rename files ripped from discs.

## Primer

After ripping an entire TV series box set, I realized there was not a good way to easily identify the video files and associate an appropriate file name and metadata. Disc Buddy attempts to solve that problem.

## What is working

* Reads a JSON from disc DB
* Shows this data in a string grid for verification

## What is planned

* Input mask association with video files from source file name
* Works with movies and box sets
* Ability to rename files based on pattern
* Association of metadata
* Auto parsing of full DiscDb data directory
